# King's Duty
This project was created as part of my higher education diploma. The aim of the diploma was to develop an interesting game concept from a creative and technical point of view.
The idea of the game is to interpret the popular Vampire Survivors and use units instead of abilities and leveling up units.
As part of the project, an infinite procedurally generated 2.5D map made of tiles, the collection of your entourage and its behavior, and a basic system for fighting enemies were implemented.
